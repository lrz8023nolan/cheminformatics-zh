# 10 · 构象生成与 3D 处理

一个分子不是一张平面图——它在三维空间里会不断变化形状，而形状往往决定活性。这一章讲清构象空间为什么重要、为什么「一个分子对应一个构象」是个糟糕的假设，再给出批量生成、优化与聚类代表性构象的完整流程。

## 分子的「第四维度」

### 10.1 为什么 2D 不够

本手册第一部分的核心是 2D 指纹——分子图的拓扑编码。但对于许多药物发现任务，拓扑相同但 3D 构象不同的分子可能有截然不同的生物活性。

考虑这个事实：一个含有 5 个可旋转键的药物分子，理论上可以存在约 3^5 = 243 个有意义的构象。如果每个构象与靶标蛋白的结合能不同，仅仅使用一个随机构象计算的 3D 描述符就可能产生高达 2-3 kcal/mol 的误差——这在结合能预测中是不可接受的。

### 10.2 距离几何（Distance Geometry）——构象生成的数学基础

RDKit 的构象生成基于**距离几何**（Distance Geometry, DG）理论。其核心思想是：

> 不直接计算 3D 坐标，而是先计算原子间距离的上界和下界（bounds），然后在这个约束空间中随机采样。

**步骤：**
1. **建立距离边界矩阵：** 对每对原子 (i, j)，根据键的连接关系和经验规则，确定其距离的可接受范围 [d_min, d_max]
2. **三角平滑（Triangle Smoothing）：** 利用三角形不等式（d_ik ≤ d_ij + d_jk），收紧边界——这是 DG 的核心算法
3. **随机采样：** 在满足边界约束的条件下，随机生成一个距离矩阵
4. **嵌入（Embedding）：** 将距离矩阵转换为 3D 坐标（通过特征值分解）
5. **粗略优化：** 用简化的力场对坐标进行小幅调整

**DG 方法的哲学意义：** 它不试图找一个"全局最优"构象，而是生成"可能的"构象。这是对构象系综本质的忠实对待——分子在溶液中并非冻结在能量最低点，而是在所有可及构象之间不断转换。

### 10.3 ETKDG——经验��识的注入

纯 DG 方法有一个问题：它生成的距离边界是基于拓扑连接和原子半径的，缺乏化学特异性。它不知道芳香环应该是平面的，也不知道某些扭转角在实验数据中倾向于特定值。

**ETKDG**（Experimental Torsion Knowledge Distance Geometry）在 DG 的基础上增加了两层约束：

1. **小分子晶体结构数据库（CSD）的扭转角偏好：** 对常见键类型的扭转角分布施加概率偏向。例如，酯基中 O=C-O-C 的扭转角在 CSD 中显示出强烈的 0°（顺式）偏好——ETKDG 会优先采样这个区域。
2. **化学知识约束（K 部分）：** 强制芳香环平面性、三键线性等基本化学规则。

ETKDGv3（当前最新的默认版本）进一步改进了对带电荷分子和大环化合物的处理。

**为什么这很重要：** 没有 ETKDG 的 DG 方法产生的构象可能在化学上"正确"（原子距离无冲突），但形状上"错误"（例如芳香环扭曲成椅式构象）。ETKDG 产生的构象更接近实验晶体结构。

### 10.4 MMFF94 力场——能量层面的细化

MMFF94（Merck Molecular Force Field）是一个"第 2 类"力场，包含键伸缩、角弯曲、扭转和静电/范德华非键相互作用的能量项。

```math
E_total = E_bond + E_angle + E_torsion + E_vdw + E_electrostatic
```

在 ETKDG 之后运行 MMFF94 优化的意义：
- ETKDG 产生的是"几何上合理"的构象
- MMFF94 将其推向"能量上更优"的构象（局部能量极小值）

**工程判断：** 对于大多数虚拟筛选任务，ETKDG 产生的构象已经足够好。MMFF94 优化主要在后两种情况中必要：(1) 你需要精确的相对能量排序（如对接前的配体制备）；(2) 分子包含不常见的价态或配位模式，ETKDG 的规则可能不适用。

### 10.5 构象系综的代表性问题

一个分子有多个构象，但我们通常需要为每个分子分配一个"代表性的"特征向量用于 ML 模型。常见的策略：

1. **全局最低能量构象：** 选能量最低的。问题——最低能量构象不一定是与蛋白结合时的"生物活性构象"
2. **聚类中心：** 用 Butina 聚类对构象分组，选每类的代表。这是更鲁棒的方法，因为它保留了结构多样性
3. **系综平均：** 对多个低能构象计算描述符，然后取均值或加权平均。信息最多，但计算开销最大
4. **所有构象作为独立样本：** 在训练时使用。增加了数据量，但引入了同一分子的多个样本之间的相关性

**实践建议：** 如果下游任务是分子性质预测（LogP、溶解度等），选最低能量构象通常足够——因为这些性质主要由拓扑决定，对构象不敏感。如果是靶标结合相关任务（对接、药效团匹配），需要使用聚类中心或保守地取多个低能构象。

### 10.6 RMSD 作为构象相似性度量

RMSD（Root Mean Square Deviation）是两个构象之间结构差异的标准度量：

```
RMSD(A, B) = sqrt( Σ_i |pos_i^A - pos_i^B|² / n )
```

其中 pos_i^A 是分子 A 中原子 i 的 3D 坐标（对齐后）。

**RMSD 的局限性：**
- 对整体平移/旋转敏感——必须先对齐
- 对大分子的整体形状变化过于敏感——两个只有末端不同的长链分子可能产生很大的 RMSD，尽管核心结构相同
- 对分子对称性处理复杂——苯环旋转 180° 在化学上等价，但 RMSD 会报告差异

在实践中，0.5 Å 是区分"相同构象"和"不同构象"的常用阈值。对于虚拟筛选中的构象聚类，0.75-1.0 Å 更实用。

## RDKit 中的构象生成

分子的 3D 形状是其生物活性的核心决定因素。RDKit 提供生成和分析分子构象的完整工具链。

### 10.7 单构象生成（ETKDG 方法）

ETKDG = Experimental Torsion Knowledge Distance Geometry，是 RDKit 的默认方法，从 2018.09 版本起替代了纯距离几何法。

```python
from rdkit.Chem import AllChem, rdDistGeom, rdMolAlign
from rdkit.Chem import rdMolDescriptors

mol = Chem.MolFromSmiles('CC(=O)OC1=CC=CC=C1C(=O)O')  # 阿司匹林

# 关键：生成 3D 构象前必须加氢
mol_with_h = Chem.AddHs(mol)

# 使用 ETKDGv3（最新版本，推荐）
params = AllChem.ETKDGv3()
params.randomSeed = 42                    # 随机种子（可复现）
result = AllChem.EmbedMolecule(mol_with_h, params)

if result == 0:
    print("构象生成成功")
else:
    print(f"构象生成失败，错误码: {result}")

# 去掉显式氢（大多数分析不需要）
mol_3d = Chem.RemoveHs(mol_with_h)
```

### 10.8 多构象生成

药物分子通常有多个低能构象。`EmbedMultipleConfs` 可以生成一个构象系综。

```python
mol_h = Chem.AddHs(mol)

params = AllChem.ETKDGv3()
params.randomSeed = 42
params.pruneRmsThresh = 0.5            # RMSD 阈值：小于 0.5 Å 的构象被视为重复
params.numThreads = 0                  # 0 = 使用所有 CPU 核心

cids = AllChem.EmbedMultipleConfs(
    mol_h,
    numConfs=100,                       # 目标构象数
    params=params
)
print(f"成功生成 {len(cids)} 个构象")
```

### 10.9 构象优化（MMFF94 力场）

ETKDG 生成的构象通常已经足够好，但对于精确的能量计算或对接，可以使用力场优化。

```python
# 批量优化所有构象
results = AllChem.MMFFOptimizeMoleculeConfs(mol_h, numThreads=0)

# results 是 list of (converged, energy) tuples
for cid, (converged, energy) in enumerate(results):
    if converged == 0:
        print(f"构象 {cid}: 收敛, 能量 = {energy:.2f} kcal/mol")
    else:
        print(f"构象 {cid}: 未收敛")
```

### 10.10 构象对齐与 RMSD 分析

```python
# 将所有构象对齐到第一个构象，计算 RMSD
rms_list = []
AllChem.AlignMolConformers(mol_h, RMSlist=rms_list)
print(f"RMSD 列表（共 {len(rms_list)} 个值）")

# 计算任意两个指定构象间的 RMSD
rms_1_9 = AllChem.GetConformerRMS(mol_h, 1, 9, prealigned=True)
print(f"构象 1 与构象 9 的 RMSD: {rms_1_9:.3f} Å")
```

### 10.11 Butina 聚类——挑选代表性构象

Butina 聚类是一种不需要预设聚类数量的层次聚类方法，广泛用于化合物库多样性筛选。

```python
from rdkit.ML.Cluster import Butina

def butina_cluster_conformers(mol, cutoff=0.75):
    """使用 Butina 聚类挑选代表性构象"""
    n_confs = mol.GetNumConformers()
    
    # 计算所有构象对的 RMSD 距离矩阵
    dists = []
    for i in range(n_confs):
        for j in range(i):
            rms = AllChem.GetConformerRMS(mol, i, j, prealigned=False)
            dists.append(rms)
    
    # Butina 聚类
    clusters = Butina.ClusterData(dists, n_confs, cutoff,
                                   isDistData=True)
    
    # 每类的第一个构象作为代表（聚类中心在列表中位置靠前）
    representatives = [c[0] for c in clusters]
    
    print(f"原始构象数: {n_confs}")
    print(f"聚类数: {len(clusters)}")
    print(f"代表性构象 ID: {representatives}")
    
    return clusters, representatives
```

### 10.12 3D 描述符

```python
# PMI（Principal Moments of Inertia）——描述分子形状
pmi1 = rdMolDescriptors.CalcPMI1(mol_h, confId=0)
pmi2 = rdMolDescriptors.CalcPMI2(mol_h, confId=0)
pmi3 = rdMolDescriptors.CalcPMI3(mol_h, confId=0)

# 归一化 PMI 比值（杆状 vs 盘状 vs 球状）
npr1 = pmi1 / pmi3   # 近 1 = 球状，近 0 = 杆状
npr2 = pmi2 / pmi3   # 近 1 = 盘状/球状，近 0 = 杆状

print(f"NPR1: {npr1:.3f}, NPR2: {npr2:.3f}")

# 回转半径
radius_of_gyration = rdMolDescriptors.CalcRadiusOfGyration(mol_h, confId=0)
print(f"回转半径: {radius_of_gyration:.2f} Å")

# 3D 自相关描述符（AUTOCORR2D 的 3D 版本）
# 需要特定模块：rdMolDescriptors
asphericity = rdMolDescriptors.CalcAsphericity(mol_h, confId=0)
eccentricity = rdMolDescriptors.CalcEccentricity(mol_h, confId=0)
print(f"非球度: {asphericity:.3f}, 偏心率: {eccentricity:.3f}")
```
