# 08 · 分子表征总论

前面七章讲的是具体工具：怎么读分子、怎么标准化、用哪种指纹。这一章退后一步，回答一个更上层的问题——**在什么场景下该选哪一层表征**。1D、2D、3D 到学习型表征，每一层能承载多少信息、代价是什么，理解这条阶梯之后，前面那些具体选择才有依据。

## 表征的层次：信息维度的阶梯

### 08.1 表征的四个层次

分子表征可以按照信息维度分为四个层次：

```
                        信息丰富度 →
    ┌──────────┬──────────────┬──────────────┬──────────────────┐
    │  0D/1D   │     2D       │     3D       │    Learned       │
    │ 标量性质  │  拓扑结构     │  空间构象     │   数据驱动表征    │
    ├──────────┼──────────────┼──────────────┼──────────────────┤
    │ MW       │ SMILES       │ 3D 坐标      │ GNN 嵌入         │
    │ LogP     │ 分子图       │ 静电势       │ ChemBERTa 嵌入    │
    │ 元素组成  │ 分子指纹     │ 形状描述符    │ Mol2vec 嵌入      │
    │          │ 2D 描述符    │ 药效团       │                  │
    ├──────────┼──────────────┼──────────────┼──────────────────┤
    │ 最简单    │ 化学信息学    │ 结构生物学    │ 深度学习         │
    │ 最快      │ 的主战场      │ 对接相关      │ 前沿方向          │
    └──────────┴──────────────┴──────────────┴──────────────────┘
```

**每层的核心问题：**

- **0D/1D：** "这个分子有多重？有多亲脂？它含多少个氢键供体？" → 描述分子的全局性质，不涉及结构
- **2D：** "它有什么官能团？骨架长什么样？两个分子在拓扑上相似吗？" → 化学信息学最成熟的层级
- **3D：** "它在空间中是什么形状？静电势如何分布？与蛋白结合时采取什么构象？" → 结构导向的药物发现
- **Learned：** "数据告诉我什么特征对预测这个性质最有用？" → 端到端学习，放弃人工定义

### 08.2 为什么没有"最好的"表征

这是一个根本性的认知。如果存在一种对所有任务都最优的表征，其他表征早就被淘汰了。现实是：

- 在溶解度预测上，2D 描述符 + XGBoost 通常不输于 GNN（甚至更好）
- 在蛋白质-配体结合亲和力预测上，3D 信息至关重要（因为结合取决于空间互补性）
- 在小数据集上，手工设计的指纹和描述符远优于学出来的嵌入（因为后者需要大量数据来训练）
- 在大数据集上，学出来的嵌入通常优于固定指纹（因为它可以针对目标任务进行优化）

**"没有免费午餐"定理在分子表征中的体现：** 每种表征都带入了一种 inductive bias（归纳偏置）——关于什么结构特征"应该"重要的先验假设。这个偏置在某些任务上有益，在另一些任务上有害。

## 1D 表征：数量胜于质量

### 08.3 标量描述符承载的信息

一个分子量（MW=180.16）本身几乎不包含结构信息。但你考虑一组描述符时，它们合在一起提供了"化学直觉的数值抽象"：

```
阿司匹林:
MW=180.16, LogP=1.31, TPSA=63.6, HBD=1, HBA=4, RotBonds=3, Rings=1
```

这些数字合在一起，有经验的药物化学家已经能判断"这是一个小的、口服吸收可能性较高的分子"。这就是 1D 表征的力量——用少而可解释的数字，捕捉关键的全局趋势。

### 08.4 1D 表征的局限性

- **结构同分异构体无法区分：** MW 和 LogP 对邻二甲苯和对二甲苯完全相同
- **局部结构变化不敏感：** 将一个 -OH 替换为 -CH₃，LogP 变化约 0.5，但描述符合集中这个信号可能被噪声淹没
- **缺乏空间信息：** 无法描述"这个官能团在分子的哪个位置"

### 08.5 1D 最适合的场景

- **高通量初筛：** Lipinski 规则、REOS 过滤器（快速排除明显不适合的分子）
- **作为 ML 模型的补充特征：** 在指纹基础上拼接描述符列，提供"全局性质"的上下文

## 2D 表征：化学信息学的核心范式

### 08.6 2D 表征的本质：分子图拓扑的编码

2D 表征试图回答一个基本问题：**如何将分子图（原子 = 节点，键 = 边）编码为固定长度的数值向量？**

这个问题不是琐碎的。分子图是异质图（不同类型的节点和边），且大小可变。ML 模型需要固定长度输入。所有 2D 表征方法本质上都是在解决这个"图 → 向量"的映射问题。

### 08.7 三大类 2D 表征的比较

| | 子结构键（MACCS） | 哈希指纹（ECFP4） | 拓扑指纹（Atom Pair） |
|---|---|---|---|
| **编码方式** | 预定义子结构存在性 | 圆形原子环境哈希 | 原子对距离分布 |
| **位含义** | 明确（bit 137 = 杂环 O） | 不明确（哈希结果） | 半可解释（可反推） |
| **覆盖完整性** | 受限于预定义列表 | 理论上可覆盖所有子结构 | 覆盖所有原子对 |
| **稀疏性** | 中等（~20-30 bits on） | 中等（~100-300 bits on） | 高（稀疏存储） |
| **对分子大小敏感** | 低（小分子也不会严重少位） | 高（大分子有更多唯一子结构） | 极高（O(n²) 对） |

### 08.8 表征中的信息丢失 —— 一个被严重低估的问题

任何 2D 表征都不可避免地丢失信息。关键是要知道**丢失的是什么**：

**SMILES 丢失的：**
- 3D 构象信息（完全没有）
- 键的精确长度和角度
- 非共价相互作用（氢键网络、π-π stacking）

**分子指纹丢失的（相对于完整分子图）：**
- 子结构之间的空间关系（两个官能团在分子的同侧还是异侧？）
- 子结构的计数信息（二元指纹中）
- 全局拓扑（分子形状的"宏观"特征）
- 哈希碰撞导致的信息混淆

**对于某些任务，丢失的信息恰好是无关的：** 对于 LogP 预测，3D 构象信息几乎无关（LogP 主要取决于原子类型和连接方式）。对于靶标结合预测，3D 构象至关重要。

### 08.9 指纹的"表征能力"(Expressiveness) 的形式化

在 ML 理论中，表征的 "expressiveness" 可以从区分能力的角度来定义：

> 表征 f 的区分能力 = 有多少对非等价分子分配了不同的表征向量。

- 分子图（完整拓扑）具有最大的区分能力——如果两个分子图不全等，它们就不同
- SMILES 保留了图的全等信息（可以完全重建）
- ECFP4 可能将不同的子结构哈希到相同的位（碰撞），因此区分能力弱于分子图
- MACCS 的区分能力最弱——如果两个分子在 166 个预定义键上恰好相同，指纹完全相同

**在实践中：** ECFP4 的碰撞率（约 5-22% 在 fpSize=2048 时）对于大多数 ML 任务是可以接受的，因为碰撞的子结构通常大小不同或位置不同，不太可能同时影响活性。

## 3D 表征：空间信息的重要性

### 08.10 2D 表征为什么会"摸不到"某些性质

考虑两种可能影响活性的情况：

**情况 A：顺反异构（E/Z）**
- 2D 图完全相同，但 3D 空间中官能团位于双键的同侧或异侧
- 2D 指纹无法区分；3D 坐标可以

**情况 B：全局形状互补**
- 两个分子拓扑完全不同，但 3D 形状几乎相同（分子模拟现象）
- 2D 指纹显示它们很不同（Tanimoto < 0.3）；3D 形状显示它们很相似

这些就是为什么仅依赖 2D 表征是不够的原因。

### 08.11 3D 表征的类型

| 表征类型 | 捕获的信息 | 旋转/平移不变性 | 计算成本 |
|----------|-----------|----------------|---------|
| 3D 坐标 | 全部空间信息 | 无（需先对齐） | 低（生成坐标后） |
| 静电势网格 | 电荷分布的空间模式 | 无（需对齐） | 高 |
| 形状描述符（PMI, 回转半径） | 全局形状特征 | 是 | 低 |
| 药效团指纹 | 药效特征点的空间排列 | 是 | 中 |
| 3D 自相关描述符 | 原子的距离分布 | 是 | 中 |

### 08.12 3D 表征的核心挑战——构象依赖性

2D 表征是确定的：一个 SMILES 总是产生同一个指纹。3D 表征不是：同一个分子在不同构象下有不同的 3D 特征。

**处理策略：**
1. **最低能量构象（单点）：** 简单但忽略了柔性
2. **系综平均（多点）：** 对多构象分别计算 3D 特征，然后取均值或加权平均
3. **动态特征（MD 轨迹）：** 分子动力学模拟中采样构象，计算时间序列特征——最准确但最昂贵

## 学习型表征：让数据决定什么是「重要」的

### 08.13 从"人工定义"到"数据驱动"

传统表征（指纹、描述符）的局限在于：它们对"哪些结构特征重要"做了先验假设。ECFP4 假设圆形原子环境重要；MACCS 假设 166 个特定子结构重要。学习型表征不预设——它通过训练数据自己学出来。

### 08.14 主要的学习型表征方法

**A. 基于序列的嵌入（SMILES → 向量）**

- **ChemBERTa / MolBERT：** 将 SMILES 当作自然语言处理，用 BERT 式架构在大规模化学库上预训练
- **原理：** 模型通过预测被遮罩的原子/片段学习 SMILES 的内部表示（语法和语义）
- **优势：** 可以利用所有可用的 SMILES 字符串，不需要标注数据
- **劣势：** SMILES 的一维序列结构与分子的二维图结构之间存在 mismatch——相邻的 SMILES token 不一定对应相邻的原子

**B. 基于图的嵌入（分子图 → 向量）**

- **GNN（GCN, GAT, GIN, MPNN）：** 直接在分子图上运行消息传递
- **原理：** 每个原子聚合邻居信息，通过多层迭代产生整个分子的嵌入向量
- **优势：** 自然适合分子图的不规则结构，对拓扑同构具有理论上的表达力保证
- **劣势：** 需要标注数据来训练（或通过自监督预训练）

**C. 基于 3D 的嵌入（分子图 + 3D 坐标 → 向量）**

- **SchNet, DimeNet++, Equiformer：** 在消息传递中融入原子间的 3D 距离和角度
- **原理：** 信息不仅沿拓扑边传播，还在空间中"感知"远距离原子对
- **优势：** 可以捕获 2D GNN 无法感知的空间相互作用
- **劣势：** 需要 3D 构象作为输入，增加了计算和数据依赖

### 08.15 学习型表征 vs 传统表征——在什么情况下应该用哪个？

| 场景 | 推荐 | 原因 |
|------|------|------|
| 标注数据 < 1000 | 传统指纹 + 描述符 | 学习型表征需要大量数据来学习有意义的特征 |
| 标注数据 1,000-10,000 | 传统表征为主，可微调预训练嵌入 | 预训练嵌入提供了较好的起点 |
| 标注数据 > 10,000 | 传统 + 学习型对比，择优 | 两者都可尝试 |
| 标注数据 > 100,000 | 从零训练 GNN | 足够数据支撑端到端学习 |
| 需要可解释性 | 传统描述符 + SHAP | 学习型嵌入的维度没有化学含义 |
| 无标注数据的预训练 | ChemBERTa / 自监督 GNN | 利用大规模无标注分子库 |

### 08.16 一个反直觉的实证结果

多项基准研究反复发现：**在中等数据量（< 10,000）的 QSAR 任务上，ECFP4 + XGBoost 的表现经常与最先进的 GNN 持平甚至更好。** 这不是说 GNN 不好，而是说 ECFP4 捕获的结构信息已经足够丰富，而 XGBoost 在处理这类表格数据时效率极高。

学习型表征的优势在两种场景中最明显：(1) 大规模数据（100,000+）；(2) 涉及 3D 空间信息的任务（如结合亲和力预测）。

## 表征选择的决策框架

### 08.17 四个核心问题

面对一个具体任务时，回答这四个问题来确定表征策略：

```
Q1: 任务的化学本质是什么？
    ├── 全局性质（LogP, 溶解度） → 1D 描述符就够了
    ├── 局部结构-活性关系 → 2D 指纹（ECFP4）
    ├── 蛋白-配体相互作用 → 3D 表征 + 对接
    └── 未知/复杂 → 多种表征组合 + 模型对比

Q2: 有多少标注数据？
    ├── < 1,000 → 传统表征（ECFP4 + 描述符 + XGBoost）
    ├── 1,000-10,000 → 传统表征 + 可微调的预训练嵌入
    └── > 10,000 → 传统与学习型对比实验

Q3: 需要可解释性吗？
    ├── 需要（说服化学家） → 传统描述符 + SHAP/LIME + MACCS
    └── 不需要（纯预测） → 可以尝试学习型表征

Q4: 有 3D 结构信息吗？
    ├── 有（蛋白结构已知） → 加入 3D 表征
    └── 无（仅配体数据） → 2D 表征为主
```

### 08.18 组合策略——工业级实践

在实践中，最鲁棒的做法不是选择"一种最佳表征"，而是**组合多种互补表征**：

```python
# 工业级特征工程策略（伪代码）
features = concatenate([
    ecfp4_fingerprint,        # 2048 位：局部圆形环境
    maccs_fingerprint,        # 167 位：可解释的子结构
    physchem_descriptors,     # ~20 维：MW, LogP, TPSA, QED 等
    rdkit_topological_fp,     # 2048 位：路径指纹（与 ECFP 互补）
])
```

**为什么组合？** 因为不同的表征在不同的结构变化模式上有不同的敏感度。ECFP4 擅长捕获局部的官能团变化，但对全局骨架变化相对不敏感。路径指纹恰好相反。两者组合比单独使用任一种都更鲁棒。

### 08.19 具体场景下的选择建议

| 任务 | 推荐表征 | 理由 |
|------|---------|------|
| 逆合成分析 | Reaction SMARTS + 分子图 | 反应取决于局部官能团匹配规则 |
| 化合物库去重 | 规范 SMILES + InChIKey | 需要精确的全等匹配，不需要距离度量 |
| 相似性搜索 | ECFP4 (2048) + Tanimoto | 工业标准，覆盖足够广的化学空间 |
| 性质预测 (ADMET) | ECFP4 + 物理化学描述符 + XGBoost | 在标注数据不足时，传统方法比 GNN 更好 |
| 虚拟筛选 | ECFP4 + 3D 形状描述符 | 2D 相似性 + 3D 形状互补 |
| 合成可及性评估 | SA_Score + 结构复杂度描述符 | 合成难度主要取决于结构复杂度 |
| 靶标结合预测 | 3D 构象 + 对接得分 + 配体描述符 | 结合亲和力取决于空间互补性 |

---

## 总结：三条铁律

1. **从简单开始，渐进增加复杂度。** ECFP4 + 描述符 + XGBoost 是任何 QSAR 任务的 baseline。如果这个 baseline 的表现已经满足需求（R² > 0.7 等），没有理由上 GNN。

2. **表征选择 = inductive bias 选择。** 每种表征都携带了"什么重要"的先验假设。ECFP4 假设圆形环境重要；描述符假设全局性质重要；GNN 让数据决定什么重要。选择最匹配任务本质的 bias。

3. **可解释性不是可选的——尤其是在工业界。** 当你告诉药物化学家"模型预测这个分子的 IC50 = 5 nM"，他的下一个问题一定是"为什么？"如果你的表征不支持解释（如深度学习嵌入），你需要有备用的解释策略（SHAP、MACCS 位分析、MMPA）。
