# 11 · 分子骨架与 R 基团分解

药物化学家讨论分子时，说的是「这个骨架换成那个取代基，活性会怎样」。骨架与 R 基团的分解，就是把这种讨论变成可计算的操作——也是从化合物库中自动提取结构-活性关系的基础。

## 药物化学的「主干」概念

### 11.1 Murcko 骨架的理论基础

Bemis 和 Murcko 在 1996 年的 *Journal of Medicinal Chemistry* 论文中提出了一个影响深远的框架：将药物分子系统性地分解为"骨架 + 侧链"。

**分解规则：**
1. 从分子图中移除所有非环、非连接环的单键连接的侧链原子
2. 保留所有环系统以及连接不同环的原子（linker）
3. 剩下的是该分子的"框架"（framework）

```
阿司匹林: CC(=O)OC1=CC=CC=C1C(=O)O
Murcko 骨架: c1ccccc1    （苯环——唯一的环系统）
```

**为什么这个概念重要：** 骨架代表了分子的"不可缩减的核心"——如果两个药物分子有相同的骨架，它们很可能结合同一靶标家族。骨架跳跃（scaffold hopping）——找到不同骨架但相同活性的分子——是现代药物发现的核心策略之一。

### 11.2 泛化骨架（Generic Scaffold）的用途

泛化骨架将所有原子替换为碳、所有键替换为单键。这产生的是一张"分子形状的拓扑图"，忽略了杂原子和键序。

**应用场景：** 化学系列聚类——识别具有相同"骨架拓扑"的分子群体，即使它们的杂原子和官能团不同。

### 11.3 R 基团分解——SAR 的数学形式化

R 基团分解（R-Group Decomposition）将一组共享公共骨架的分子系统地拆分为"核心 + 各位置的取代基表"。

**数学上，这是图匹配问题：** 
- 找到核心骨架在每个分子中的子图同构
- 标记匹配的原子
- 收集每个位置（attachment point）上的非匹配子图作为 R 基团

**输出格式**——以苯环为核心、苯环衍生物为例：

| 分子 | R1 | R2 | R3 |
|------|-----|-----|-----|
| 氟苯 | F | H | H |
| 间氟甲苯 | F | CH₃ | H |
| 间氟氯苯 | F | Cl | H |

这个表格是构效关系（SAR）分析的起点：你可以直接比较"当 R1 从 F 变为 Cl 时，活性变化了多少"。

### 11.4 MMPA——最纯粹的 SAR 分析单元

Matched Molecular Pair Analysis（MMPA）找到仅在一个结构变换上不同的分子对。

**MMP 的定义：** 两个分子 A 和 B，存在一个公共子结构 M，使得 A = M ∪ g1，B = M ∪ g2（g1 ≠ g2）。

**化学意义：** 如果 A 和 B 的活性不同，这个差异只能归因于 g1 → g2 的变换。这是最干净的结构-活性信号。

**MMPA 的实际价值：** 合成化学家经常问"如果我把这个位置的 -H 换成 -CH₃，活性会变吗？"——MMPA 可以系统性地回答这类问题，通过数据库中的已有数据。

## Murcko 骨架与 R 基团分解

### 11.5 Murcko 骨架

Murcko 骨架（Bemis-Murko framework）是药物化学中的核心概念：将分子拆分为"环系统骨架 + 侧链"。

```python
from rdkit.Chem.Scaffolds import MurckoScaffold

mol = Chem.MolFromSmiles('CC(=O)OC1=CC=CC=C1C(=O)O')  # 阿司匹林

# 提取 Murcko 骨架（保留环系统和连接环的 linker）
scaffold = MurckoScaffold.GetScaffoldForMol(mol)
print(f"骨架 SMILES: {Chem.MolToSmiles(scaffold)}")

# 泛化骨架：将所有原子类型替换为碳，所有键替换为单键
generic_scaffold = MurckoScaffold.MakeScaffoldGeneric(scaffold)
print(f"泛化骨架: {Chem.MolToSmiles(generic_scaffold)}")
```

**批量提取骨架到 DataFrame：**

```python
PandasTools.AddMurckoToFrame(
    df_smiles,
    molCol='ROMol',
    MurckoCol='Murcko_SMILES'
)

# 泛化版本
PandasTools.AddMurckoToFrame(
    df_smiles,
    molCol='ROMol',
    MurckoCol='Murcko_Generic',
    Generic=True
)
```

### 11.6 R 基团分解（R-Group Decomposition）

给定一个公共核心骨架，自动识别每个分子上各位置的取代基。这是 SAR 分析的核心工具。

```python
from rdkit.Chem import rdRGroupDecomposition

# 定义核心骨架
core = Chem.MolFromSmiles('c1ccccc1')  # 苯环

# 一组苯环衍生物
mols = [Chem.MolFromSmiles(s) for s in [
    'c1c(F)cccc1',      # 氟苯
    'c1c(Cl)cccc1',     # 氯苯
    'c1c(O)cccc1',      # 苯酚
    'c1c(F)c(C)ccc1',   # 间氟甲苯
    'c1cc(Cl)c(F)cc1',  # 间氟氯苯
]]

# 执行 R 基团分解
groups, unmatched = rdRGroupDecomposition.RGroupDecompose(
    [core], mols,
    asSmiles=True,       # 以 SMILES 返回结果
    asRows=False
)

# 转为 DataFrame
df_rgroups = PandasTools.RGroupDecompositionToFrame(
    groups, mols,
    include_core=False   # 不包含核心列
)

print(df_rgroups)
```

### 11.7 侧链替换与核心替换

```python
# 移除侧链（保留核心 + 连接点标记）
mol = Chem.MolFromSmiles('BrCCc1cncnc1C(=O)O')
core = Chem.MolFromSmiles('c1cncnc1')

sidechains_removed = Chem.ReplaceSidechains(mol, core)
print(Chem.MolToSmiles(sidechains_removed, True))  # [1*]c1cncnc1[5*]

# 移除核心（保留侧链）
sidechains_only = Chem.ReplaceCore(mol, core)
print(Chem.MolToSmiles(sidechains_only, True))  # [1*]CCBr.[5*]C(=O)O

# 拆分为独立分子
frags = Chem.GetMolFrags(sidechains_only, asMols=True)
for i, frag in enumerate(frags):
    print(f"侧链 {i}: {Chem.MolToSmiles(frag, True)}")
```

## MMPA：匹配分子对分析

### 11.8 Matched Molecular Pair Analysis (MMPA)

MMPA 找出一对分子之间的单一结构变换——例如将 -H 替换为 -CH₃。这能直接量化"一个原子/基团的变化对活性的影响"。

```python
# RDKit 内置 MMP 支持
from rdkit.Chem import rdMMPA

# 找出一对分子的变换
mol1 = Chem.MolFromSmiles('c1ccccc1O')     # 苯酚
mol2 = Chem.MolFromSmiles('c1ccccc1N')     # 苯胺

# 使用 rdMMPA 分析变换
pairs = rdMMPA.FindMMP(
    [mol1, mol2],
    maxBondCuts=1,      # 最多切断 1 个键
    maxVariableSize=10  # 变化部分最多 10 个重原子
)

for pair in pairs:
    print(f"变换: {pair}")
```
