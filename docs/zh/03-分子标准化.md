# 03 · 分子标准化

同一张化合物表里，阿司匹林可能以游离酸、钠盐、带结晶水等五种形式出现。如果直接拿去建模，模型学到的会是数据录入格式的差异，而不是化学规律。这一章先讲清标准化为什么是必需的，再给出生产可用的标准化函数。

## 为什么不能直接拿原始数据建模

### 03.1 问题的本质：同一实体，多种面目

假设你从三个数据源拿到了"乙酸"的 SMILES：

```
来源A（供应商目录）: CC(=O)O          # 中性乙酸
来源B（生物活性库）: CC(=O)[O-]      # 乙酸根负离子
来源C（化学注册）:  [Na+].CC(=O)[O-] # 乙酸钠盐
```

这三个字符串在字节层面完全不同。如果不标准化，它们会被当作三个不同的分子，分配三个不同的指纹，分别建模——然后你的 QSAR 模型会发现同一化合物的三种形式竟然有不同的预测值。这就是为什么标准化不是"锦上添花"，而是所有化学信息学 pipeline 的第零步。

### 03.2 每一步解决的化学问题

**步骤 1：Sanitize（基础检查）**

从 SDF 文件或其他非 SMILES 来源读入分子时，价态可能未定义、芳香性可能未感知。`Chem.SanitizeMol()` 做三件事：
- 为每个原子计算隐式氢数量（基于标准价态表）
- 将交替单双键的环识别为芳香环（Kekulé 化）
- 验证整体结构的化学合理性

**步骤 2：去盐 / 保留最大有机片段**

有机盐（如盐酸盐、钠盐）在固态和货架上以盐形式存在，但在溶液中解离。药物化学中我们关心的几乎总是有机部分。`LargestFragmentChooser(preferOrganic=True)` 的逻辑是基于有机化学的直觉：如果碎片 A 含碳而碎片 B 是 Na⁺ 或 Cl⁻，保留 A。

**边缘案例：** 季铵盐（如胆碱）的电荷是永久的，不能"中和"。标准化管线中的 `Uncharger` 默认会尝试中和其他可离子化基团，但应保留季铵正电荷。这就是为什么 `Uncharger` 使用基于 SMARTS 的规则而非盲目去电荷。

**步骤 3：Normalize（官能团标准化）**

不同的化学家画同样的官能团可能用不同的共振式。以硝基为例：

```
[N+](=O)[O-]   vs   [N](=O)=O
```

两者在化学上是等价的（都是硝基的共振式），但作为子结构完全不同的 SMARTS。Normalizer 使用预定义的 SMARTS 变换规则，将所有这些变体映射到统一的表示。

**步骤 4：Uncharge（电荷中和）**

可离子化基团的质子化状态取决于 pH。在生理 pH 7.4 下，羧酸大多以负离子形式存在，胺大多质子化。但对于机器学习建模，通常的策略是移除所有 pH 依赖的电荷，将它们统一为中性形式——因为在不知道具体 assay 条件的情况下，中性形式是最小偏见的表示。

**争议点：** 这个做法并不完美。如果你的模型要预测在 pH 2（胃环境）下的性质，将羧酸统一为中性就会引入偏差。但作为通用 pipeline 的默认策略，"先标准化为中性，需要时再加回来"是业界（ChEMBL、PubChem、canSAR）的共识。

**步骤 5：互变异构体标准化**

这是最复杂的一步。以华法林（warfarin）为例，它在溶液中可以存在 40 种不同的互变异构体。酮-烯醇互变是最著名的例子：

```
乙烯醇（烯醇式）: C=CO      →  互变  →      乙醛（酮式）: CC=O
（较不稳定）                                    （较稳定）
```

**核心困难：** 最稳定的互变异构体取决于溶剂、温度、pH 和其他环境因素——没有"通用的正确互变异构体"。TautomerEnumerator 的策略不是找出"最稳定"的形式（那需要量子化学计算），而是生成一个**规范的任意互变异构体**——确保同一个分子总是被映射到同一个表示。

**这在 ML 中的意义：** 只要训练集和测试集使用相同的标准化管线，规范互变异构体就是一致的。不一致的互变异构体处理会导致可高达 67% 的分子在两个数据库中产生不同的指纹——这意味着模型学到的是标准化算法的 artifact，而不是真实的化学规律。

### 03.3 标准化与否：一个工程判断

一个实用规则：对于 ML 建模和数据库去重——必须标准化。对于化学结构存储——保留原始形式，标准化作为预处理步骤而非永久修改。

## RDKit 中的标准化流程

真实世界的化学数据充满"噪音"：不同的质子化状态、盐形式、互变异构体。标准化是任何 pipeline 的第一步——否则同一个分子的不同表示会被当作两个不同的实体。

RDKit 的标准化管线通过 `rdMolStandardize` 模块实现。顺序很重要，推荐流程如下：

### 03.4 Sanitize（基础检查与修复）

`Chem.SanitizeMol()` 执行价态分配、Kekulé 化、芳香性感知等。从 SMILES 读取时通常已自动执行，但从 SDF 或其他来源读入时需要显式调用。

```python
mol = Chem.MolFromMolFile("sketch.mol", sanitize=False)    # 跳过自动 sanitize
try:
    Chem.SanitizeMol(mol)
except Exception as e:
    print(f"Sanitize 失败: {e}")
```

### 03.5 Normalize（官能团标准化）

将不同画法的同一官能团统一（如硝基的两种共振式、磺酸的写法等）。

```python
normalizer = rdMolStandardize.Normalizer()
mol = normalizer.normalize(mol)

# 原地修改版本
normalizer.normalizeInPlace(mol)
```

### 03.6 Uncharge（电荷中和）

将可以质子化/去质子化的基团转为中性形式（如羧酸盐 → 羧酸）。

```python
uncharger = rdMolStandardize.Uncharger(canonicalOrdering=True)
mol = uncharger.uncharge(mol)
```

`canonicalOrdering=True` 确保永远产生相同的结果，不依赖原子序号。

### 03.7 Tautomer Canonicalization（互变异构体标准化）

酮-烯醇互变等不同互变异构体统一为规范形式。

```python
enumerator = rdMolStandardize.TautomerEnumerator()
mol = enumerator.Canonicalize(mol)
```

### 03.8 Fragment Removal / Largest Fragment（去盐/去溶剂）

移除反离子、溶剂分子，只保留最大的有机片段。这是处理"盐形式"分子的标准方法。

```python
# 方法一：LargestFragmentChooser（更精细控制）
chooser = rdMolStandardize.LargestFragmentChooser(preferOrganic=True)
mol = chooser.choose(mol)

# 方法二：FragmentRemover（简单去盐）
remover = rdMolStandardize.FragmentRemover()
mol = remover.remove(mol)
```

`preferOrganic=True` 确保在有机片段和无机盐共存时优先保留有机部分。

### 03.9 完整标准化函数（生产级）

```python
def standardize_mol(mol):
    """完整的分子标准化管线。
    
    顺序：Sanitize → 取最大片段 → Normalize → Uncharge → 互变异构体标准化
    """
    if mol is None:
        return None
    
    try:
        Chem.SanitizeMol(mol)
    except Exception:
        return None
    
    # 保留最大有机片段（去盐、去溶剂）
    chooser = rdMolStandardize.LargestFragmentChooser(preferOrganic=True)
    mol = chooser.choose(mol)
    
    # 官能团标准化
    normalizer = rdMolStandardize.Normalizer()
    mol = normalizer.normalize(mol)
    
    # 电荷中和
    uncharger = rdMolStandardize.Uncharger(canonicalOrdering=True)
    mol = uncharger.uncharge(mol)
    
    # 互变异构体标准化
    enumerator = rdMolStandardize.TautomerEnumerator()
    mol = enumerator.Canonicalize(mol)
    
    return mol

# 使用 Cleanup（一站式方法）
# 等价于上述全流程，但参数更统一
mol_clean = rdMolStandardize.Cleanup(mol)
```

### 03.10 验证标准化效果

```python
# 阿司匹林的钠盐形式
aspirin_na = Chem.MolFromSmiles("[Na+].CC(=O)Oc1ccccc1C(=O)[O-]")
print(f"标准化前: {Chem.MolToSmiles(aspirin_na)}")

aspirin_std = standardize_mol(aspirin_na)
print(f"标准化后: {Chem.MolToSmiles(aspirin_std)}")
# 输出: CC(=O)Oc1ccccc1C(=O)O  （去掉了 Na+，中和了羧酸根）
```
