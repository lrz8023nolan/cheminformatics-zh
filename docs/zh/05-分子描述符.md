# 05 · 分子描述符

指纹给出的是「有没有某个结构片段」，描述符给出的是「数值是多少」。两者互补：指纹擅长区分结构，描述符擅长刻画性质趋势。这一章覆盖常用理化描述符、批量计算，以及 Lipinski 五规则的快速类药性判断。

## 用数字「翻译」分子性质

### 05.1 描述符与指纹的区别

| | 描述符 | 指纹 |
|---|---|---|
| 输出 | 标量（一个数字） | 向量（数百至数千位） |
| 维度 | 1 | 高维 |
| 解释 | 直接（"分子量"有明确物理含义） | 间接（需要反推bit含义） |
| 信息量 | 低（单个描述符捕获的信息有限） | 高（整个指纹编码了结构全貌） |
| 用途 | 可解释性质、过滤规则、理化性质预测 | 相似性搜索、QSAR、虚拟筛选 |

### 05.2 药物化学中最重要的描述符

**LogP（脂水分配系数）**

LogP = log([化合物在辛醇中的浓度] / [化合物在水中的浓度])

- LogP 低（< 1）：亲水，水溶性好但穿透细胞膜能力弱
- LogP 高（> 5）：亲脂，穿透性好但水溶性差、代谢清除快
- 理想范围（口服药）：1-3

RDKit 使用 Crippen 的原子贡献法计算：将 LogP 视为各原子类型贡献之和。这不是实验值，是估计值，但对于高通量虚拟筛选是足够好的近似。

**TPSA（拓扑极性表面积）**

TPSA 是分子中极性原子（O、N 及其连接的 H）的表面积之和。它预测两个关键性质：
- 口服吸收：TPSA < 140 Å² 通常意味着可接受的口服生物利用度
- 血脑屏障穿透：TPSA < 90 Å² 通常意味着可以进入中枢神经系统

TPSA 的计算不需要 3D 构象——它是从 2D 拓扑结构和预校准的原子贡献表直接计算的，因此速度快且构象无关。

**氢键供体/受体数（HBD / HBA）**

- HBD（氢键供体）：分子中能提供氢原子的 O-H 和 N-H 基团数量
- HBA（氢键受体）：分子中能接受氢原子的 O 和 N 原子数量

氢键是药物-靶标结合的核心驱动力，同时也是影响溶解性和渗透性的关键因素。Lipinski 五规则中 HBD ≤ 5、HBA ≤ 10 的阈值来自对大量口服药数据的统计分析。

**可旋转键数**

- 定义：非环的、非末端的单键数量
- 分子越"柔"（可旋转键越多），与靶标结合时需要付出的熵代价越大
- 经验规则：≤ 10 是可接受的药物分子范围

### 05.3 Lipinski 五规则的理论背景

Lipinski 在 1997 年分析了 2245 个进入 II 期临床的候选药物，发现大多数口服活性药物满足以下规则：

| 规则 | 阈值 | 理论基础 |
|------|------|----------|
| MW ≤ 500 | 分子量 | 大于 500 的分子难以通过被动扩散穿透细胞膜 |
| LogP ≤ 5 | 脂溶性 | 过高 LogP 导致水溶性差、代谢清除快 |
| HBD ≤ 5 | 氢键供体 | 过多 HBD 导致脱溶剂化能过高 |
| HBA ≤ 10 | 氢键受体 | 过多 HBA 同样增加脱溶剂化成本 |

**关键理解：** Lipinski 规则是统计规律，不是物理定律。许多成功的药物（如环孢素、紫杉醇）违反了多条规则。它的正确使用方式是作为**快速筛选过滤器**，而非硬性排除标准。违反 1-2 条规则但活性极高的分子仍然值得关注。

## RDKit 中的描述符计算

描述符是标量值（单个数字），比指纹更"低维"但更"可解释"。RDKit 内置了 200+ 描述符。

### 05.4 常用物理化学描述符

```python
mol = Chem.MolFromSmiles("CC(=O)OC1=CC=CC=C1C(=O)O")    # 阿司匹林

# 基础性质
mw = Descriptors.MolWt(mol)              # 分子量
logp = Descriptors.MolLogP(mol)          # LogP（脂水分配系数，Crippen 方法）
tpsa = Descriptors.TPSA(mol)             # 拓扑极性表面积
hba = Descriptors.NumHAcceptors(mol)     # 氢键受体数
hbd = Descriptors.NumHDonors(mol)        # 氢键供体数
rot_bonds = Descriptors.NumRotatableBonds(mol)   # 可旋转键数
rings = Descriptors.RingCount(mol)       # 环数
arom_rings = Descriptors.NumAromaticRings(mol)   # 芳香环数
heavy_atoms = Descriptors.HeavyAtomCount(mol)    # 重原子数

print(f"MW: {mw:.2f}, LogP: {logp:.2f}, TPSA: {tpsa:.2f}")
print(f"HBA: {hba}, HBD: {hbd}, RotBonds: {rot_bonds}")
```

### 05.5 分子式

```python
formula = rdMolDescriptors.CalcMolFormula(mol)
exact_mw = rdMolDescriptors.CalcExactMolWt(mol)    # 精确分子量（单同位素质量）

print(f"分子式: {formula}")         # C9H8O4
print(f"精确分子量: {exact_mw:.4f}") # 180.0423
```

### 05.6 批量计算所有描述符

```python
# 获取所有可用描述符名称
desc_names = [name for name, _ in Descriptors._descList]
print(f"RDKit 共提供 {len(desc_names)} 个描述符")

# 为单个分子计算所有描述符
def calc_all_descriptors(mol):
    """计算 RDKit 全部 200+ 描述符"""
    descs = {}
    for name, func in Descriptors._descList:
        try:
            descs[name] = func(mol)
        except Exception:
            descs[name] = np.nan
    return descs

# 批量处理
def mols_to_descriptors_df(mols):
    """将分子列表转为描述符 DataFrame"""
    data = [calc_all_descriptors(mol) for mol in mols]
    return pd.DataFrame(data)

# 示例
smiles_list = ["CCO", "c1ccccc1", "CC(=O)O", "CC(=O)OC1=CC=CC=C1C(=O)O"]
mols = [Chem.MolFromSmiles(s) for s in smiles_list]
desc_df = mols_to_descriptors_df(mols)
print(desc_df[["MolWt", "MolLogP", "NumHAcceptors", "NumHDonors"]])
```

### 05.7 Lipinski 五规则（类药性快速评估）

```python
def check_lipinski(mol):
    """检查分子是否违反 Lipinski 五规则（类药性评估）"""
    mw = Descriptors.MolWt(mol)
    logp = Descriptors.MolLogP(mol)
    hbd = Descriptors.NumHDonors(mol)
    hba = Descriptors.NumHAcceptors(mol)
    
    violations = 0
    if mw > 500: violations += 1
    if logp > 5: violations += 1
    if hbd > 5: violations += 1
    if hba > 10: violations += 1
    
    return {
        "MW": mw, "LogP": logp, "HBD": hbd, "HBA": hba,
        "Violations": violations,
        "DrugLike": violations <= 1    # 违反不超过 1 条视为类药
    }

result = check_lipinski(aspirin)
print(result)    # 阿司匹林: MW=180, LogP=1.3, HBD=1, HBA=4, 0 violations
```
