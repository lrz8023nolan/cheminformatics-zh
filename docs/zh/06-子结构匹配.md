# 06 · 子结构匹配

子结构匹配是化学领域独有的能力：用一段模式描述「我要找什么样的结构」，然后在整个化合物库里检索。它的实现依赖 SMARTS 这门模式语言，也是所有结构过滤、警示结构筛查的基础。

## 分子识别的逻辑引擎

### 06.1 从 SMILES 到 SMARTS

SMILES 描述一个特定的分子。但如果你想问"我的化合物库里有多少分子含有羧基？"，你需要一种能描述**一类分子**的语言。这就是 SMARTS（SMILES Arbitrary Target Specification）的用途。

SMILES 和 SMARTS 的关系 ≈ 具体字符串和正则表达式的关系：

```
SMILES "CC(=O)O"      → "含有乙酸结构"（限于乙酸本身）
SMARTS "C(=O)[OH]"    → "含有羧基片段"（匹配所有羧酸）
SMARTS "[CX4]"        → "含有 sp3 碳"（逻辑表达式）
SMARTS "[F,Cl,Br,I]"  → "含有卤素"（逻辑或）
SMARTS "a"            → "含有芳香原子"（通配符）
```

SMARTS 的原子原语（atomic primitives）包括：
- 元素符号：`C`, `N`, `O`, `[Na]`, `[Cl]`
- 通配符：`*`（任意原子），`a`（芳香原子），`A`（脂肪族原子）
- 逻辑表达式：`,`（或），`;`（与），`!`（非）
- 度数指定：`D2`（连接两个重原子的原子），`X4`（总连接数 = 4）
- 氢计数：`H2`（连接 2 个氢），`h1`（隐式氢计数 = 1）
- 电荷：`+`（正），`-`（负）

### 06.2 子图同构的化学意义

子结构匹配在计算机科学中对应**子图同构问题**（Subgraph Isomorphism），这是一个 NP 完全问题。但在化学分子图上，由于分子图的特殊性质（每个原子的度数受化合价限制，通常 ≤ 6），实际算法在药物分子上运行极快。

`mol.HasSubstructMatch(query)` 的语义：
- query 中的每个原子必须匹配 mol 中的一个互不相同的原子
- query 中的每个键必须匹配 mol 中相应原子之间的一条键
- 匹配规则：query 中未指定的属性不限制 target（例如 query 不指定芳香性，则 target 可以是芳香也可以是脂肪）

**关键陷阱：** SMILES 字符串 `"CO"` 作为 SMARTS 查询使用时，它的含义是"存在 C 原子和 O 原子通过单键连接"——不要求 C 的化合价完全匹配，也不要求这是分子中的完整片段。这就解释了为什么 `"CO"` 作为 SMARTS 可以匹配 `CCO`（乙醇）：乙醇中确实存在 C-O 单键。

### 06.3 MCS——最大公共子结构

逆合成分析和骨架跃迁中的核心操作：给定两个活性分子，找出它们共享的最大子结构。这暗示这个公共骨架可能是药效团的核心部分。

`rdFMCS.FindMCS()` 的参数选择反映了化学判断：

- `ringMatchesRingOnly=True`：环原子只能匹配环原子。为什么？一个芳香环与一个脂肪链即使有相同数量的碳原子，化学行为完全不同。
- `completeRingsOnly=True`：只返回完整环。为什么？一个被切半的芳香环在化学上没有意义，不能代表真实的子结构。
- `timeout` 参数：MCS 在最坏情况下是指数时间复杂度，对于大分子可能永远跑不完。超时是工程上的必要保护。

## SMARTS 与子结构搜索

子结构匹配是化学信息学中最基础的操作之一：判断某个化学片段（子结构）是否存在于分子中。

### 06.4 SMARTS 基础

SMARTS 是 SMILES 的超集，允许用通配符和逻辑表达式描述子结构模式。

```python
# 常见 SMARTS 模式及其含义
patterns = {
    "羧酸": "C(=O)[OH]",
    "伯胺": "[NH2]",
    "芳香环": "a",
    "芳香碳": "c",
    "任意原子": "*",
    "羰基": "C=O",
    "脂肪链碳": "[CX4]",        # 四配位碳（sp3）
    "芳香氮": "n",
    "羟基": "[OH]",
    "卤素": "[F,Cl,Br,I]",
    "硝基": "[N+](=O)[O-]",
    "酰胺": "C(=O)N",
    "酯": "C(=O)O[#6]",          # 酯基中的氧连碳
}

for name, smarts in patterns.items():
    patt = Chem.MolFromSmarts(smarts)
    print(f"{name}: {smarts}")
```

### 06.5 子结构搜索

```python
mol = Chem.MolFromSmiles("CC(=O)OC1=CC=CC=C1C(=O)O")    # 阿司匹林

# 检查分子是否包含指定子结构
carboxyl = Chem.MolFromSmarts("C(=O)[OH]")
print(mol.HasSubstructMatch(carboxyl))    # True（阿司匹林有羧基）

# 获取第一个匹配的原子索引
match = mol.GetSubstructMatch(carboxyl)
print(f"匹配原子索引: {match}")    # e.g., (1, 2, 3) —— 对应查询原子的顺序

# 获取所有匹配（同一子结构可能出现多次）
matches = mol.GetSubstructMatches(carboxyl)
print(f"匹配数: {len(matches)}")
for i, m in enumerate(matches):
    print(f"  匹配 {i+1}: {m}")

# 限制最大匹配数（大分子性能优化）
matches = mol.GetSubstructMatches(carboxyl, maxMatches=10)
```

### 06.6 子结构匹配的可视化

```python

mol = Chem.MolFromSmiles("CC(=O)OC1=CC=CC=C1C(=O)O")
```

### 06.7 用子结构过滤化合物库

```python
def filter_by_substructure(smiles_list, smarts_pattern):
    """筛选包含指定子结构的分子"""
    patt = Chem.MolFromSmarts(smarts_pattern)
    if patt is None:
        raise ValueError(f"无效 SMARTS: {smarts_pattern}")
    
    results = []
    for smi in smiles_list:
        mol = Chem.MolFromSmiles(smi)
        if mol and mol.HasSubstructMatch(patt):
            results.append(smi)
    return results

# 筛选含羧基的化合物
hits = filter_by_substructure(
    ["CCO", "CC(=O)O", "c1ccccc1O", "CC(=O)OC1=CC=CC=C1C(=O)O"],
    "C(=O)[OH]"
)
print(hits)    # ['CC(=O)O', 'CC(=O)OC1=CC=CC=C1C(=O)O']
```

### 06.8 最大公共子结构（MCS）

找出两个或多个分子之间最大的公共子结构——在骨架跃迁和先导化合物优化中常用。

```python
mol1 = Chem.MolFromSmiles("O=C(NCc1cc(OC)c(O)cc1)CCCC/C=C/C(C)C")
mol2 = Chem.MolFromSmiles("CC(C)CCCCCC(=O)NCC1=CC(=C(C=C1)O)OC")

mcs_result = rdFMCS.FindMCS(
    [mol1, mol2],
    ringMatchesRingOnly=True,     # 环原子只能匹配环原子
    completeRingsOnly=True,       # 只返回完整环
    timeout=5                     # 超时设置（秒）
)

print(f"MCS 原子数: {mcs_result.numAtoms}")
print(f"MCS 键数: {mcs_result.numBonds}")
print(f"MCS SMARTS: {mcs_result.smartsString}")

# 用 MCS 结果创建查询分子并可视化
mcs_mol = Chem.MolFromSmarts(mcs_result.smartsString)
matches = [mol1.GetSubstructMatch(mcs_mol), mol2.GetSubstructMatch(mcs_mol)]
img = Draw.MolsToGridImage(
    [mol1, mol2],
    highlightAtomLists=matches,
    legends=["Mol1", "Mol2"],
    subImgSize=(400, 250)
)
```
