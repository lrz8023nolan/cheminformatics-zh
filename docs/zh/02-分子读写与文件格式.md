## 分子的读写与可视化

### 02.1 SMILES → Mol 对象

SMILES（Simplified Molecular Input Line Entry System）是最常用的分子文本表示。RDKit 提供双向转换。

```python
# 基础用法
ethanol = Chem.MolFromSmiles("CCO")
aspirin = Chem.MolFromSmiles("CC(=O)OC1=CC=CC=C1C(=O)O")
benzene = Chem.MolFromSmiles("c1ccccc1")

# 关键检查：MolFromSmiles 对无效 SMILES 返回 None，必须检查！
invalid = Chem.MolFromSmiles("CXX")    # 无效 SMILES
print(invalid is None)                 # True

# 批量转换（标准做法）
smiles_list = ["CCO", "c1ccccc1", "CC(=O)O", "invalid_smiles"]
mols = []
for smi in smiles_list:
    mol = Chem.MolFromSmiles(smi)
    if mol is not None:
        mols.append(mol)
    else:
        print(f"警告：无法解析 {smi}")
```

### 02.2 Mol → SMILES

```python
# 标准（canonical）SMILES —— 原子的规范排序，同一分子始终产出相同 SMILES
canonical_smi = Chem.MolToSmiles(aspirin)
print(canonical_smi)    # CC(=O)Oc1ccccc1C(=O)O

# 含立体化学信息的 isomeric SMILES
isomeric_smi = Chem.MolToSmiles(aspirin, isomericSmiles=True)

# 含所有 H 原子的 SMILES
all_h_smi = Chem.MolToSmiles(aspirin, allHsExplicit=True)
```

### 02.3 SDF / MOL 文件读写

SDF（Structure Data File）是工业界的标准格式，可存储一个或多个分子及关联属性。

```python
# --- 读取单个 MOL 文件 ---
mol = Chem.MolFromMolFile("molecule.mol")

# --- 读取多分子 SDF 文件 ---
# SDMolSupplier 是惰性迭代器，不会一次性加载所有分子到内存
supplier = Chem.SDMolSupplier("molecules.sdf")
mols = [mol for mol in supplier if mol is not None]
print(f"成功读取 {len(mols)} 个分子")

# --- 写入 SDF 文件 ---
writer = Chem.SDWriter("output.sdf")
for mol in mols:
    # 可设置分子属性，会写入 SDF 的 tag 字段
    mol.SetProp("_Name", "Compound_001")
    mol.SetProp("Activity", "8.5")
    writer.write(mol)
writer.close()    # 必须关闭！

# --- 使用 with 语句（推荐） ---
with Chem.SDWriter("output.sdf") as w:
    for mol in mols:
        w.write(mol)
```

### 02.4 分子可视化

```python
# 单个分子
img = Draw.MolToImage(aspirin, size=(300, 200))
img.show()    # 在 Jupyter 中直接显示；在脚本中可用 img.save("aspirin.png")

# 多个分子（网格）
mols_list = [ethanol, aspirin, benzene]
img = Draw.MolsToGridImage(
    mols_list,
    molsPerRow=3,
    subImgSize=(250, 200),
    legends=["Ethanol", "Aspirin", "Benzene"]
)
img.show()
```
