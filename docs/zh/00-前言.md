# 00 · 前言

## 这本书是怎么组织的

每一章都分成两段：

- **原理段**回答"为什么"。为什么必须标准化、为什么指纹会碰撞、为什么相似性没有客观答案。
- **实操段**回答"怎么写"。可运行的代码、参数的含义、生产环境要注意什么。

顺序是有意为之。**先看原理再看代码**，你会知道每个参数在做什么取舍；反过来，你只会记住一堆调用方式，换个任务就不知道该怎么改。

章节内部的小节按 `章号.序号` 编号（如 `03.5`），交叉引用也用同一套编号，方便互相跳转。

第一部分的推荐读法是顺着读；如果你只有具体问题，可以直接跳到第 14 章——那里按"症状 → 原因 → 怎么改"列了最常踩的坑。

## 版本约定

- **RDKit 2025.09.x**。RDKit 的 API 在版本间变动较大，文中的行为描述都以这个版本为准。
- **新旧 API 会同时标注**。典型例子是指纹生成：新版 `rdFingerprintGenerator`（推荐）和旧版 `AllChem.GetMorganFingerprint*`（仍可用但不再推荐）。文中会说明两者的差别，并建议统一用新 API——**不要在同一个项目里混用**，理由见 14.7。
- 如果某个行为在不同版本间有差异，会单独注明。

## 代码约定

- 代码片段**都可以直接运行**，只依赖 RDKit。个别需要额外依赖的地方会标明。
- 为了段落独立，片段里有时会重复导入和创建对象。**照抄到生产代码时请自行合并**——比如指纹生成器应该建一次就复用，不要在循环里反复创建（见 14.7）。
- 示例分子一律使用公开可得的化合物（乙醇、阿司匹林、咖啡因等）。

## 阅读前提

有基础的 Python 使用经验即可，**不需要化学信息学背景**。涉及化学概念的地方会解释直觉，不假设读者有药物化学训练。

## 关于内容来源

每一条结论都尽量给出出处，涉及具体算法和标准化的部分引用了原始文献，汇总在附录 B。凡是有争议或存在多套做法的，文中会指出争议点而不是给出唯一答案——比如 03 章关于"是否把所有分子中和为中性"的讨论。

如果发现错误或过时的地方，欢迎提 issue。化学信息学里一个错误的默认参数可能导致整批数据出错，所以涉及 API 行为和版本差异的内容，请附上你的验证方式。
