# 01 · 导论：为什么需要「表示」分子

## 从化学直觉到计算机语言

### 01.1 核心问题：计算机不认识分子

给化学家看苯环的结构式，他立刻知道这是什么。但计算机只理解数字。所以化学信息学的第一个问题，也是最根本的问题，就是：

> 如何用一种计算机能处理的形式，完整、唯一、紧凑地描述一个分子？

这看似简单，实则充满陷阱。一个乙醇分子至少有六种"画法"：

```
CCO     C-O-C 错误！    OCC      C(O)C     [CH3][CH2][OH]      ethanol（英文名）
```

第二种是错的，但其余的四个字符串描述了同一个分子。如果计算机把 `CCO` 和 `OCC` 当成两个不同的东西，数据库里同一个分子会被重复注册多次，你的机器学习模型会收到矛盾的标签——崩溃从这里开始。

### 01.2 线表示法：SMILES 的设计哲学

SMILES（Simplified Molecular Input Line Entry System）由 David Weininger 在 1980 年代提出。它的核心设计取舍是：

| 取舍维度 | SMILES 的选择 | 为什么 |
|----------|--------------|--------|
| 可读性 vs 计算机优化 | 偏向人类可读 | 化学家需要能手写和阅读 |
| 灵活性 vs 唯一性 | 允许同一分子有多种写法 | 方便人类输入（从任意原子开始即可） |
| 简洁性 vs 完整性 | 使用隐式氢、省略单键 | 减少存储空间（典型分子仅 ~1.6 bytes/atom） |

**图遍历是核心机制。** SMILES 的本质是通过深度优先搜索遍历分子图，将访问路径编码为字符串。所以同样从乙醇出发：

- 从 C1 开始遍历 → `CCO`
- 从 O 开始遍历 → `OCC`

不同的起始点产生不同的 SMILES，但它们指向同一个分子图。

### 01.3 规范 SMILES（Canonical SMILES）

如果能规定"永远从这个原子开始、按这个方向遍历"，就能保证同一分子永远产出同一个字符串。这就是规范化的核心。

Weininger 提出的 CANGEN 算法分为两步：
1. **CANON 步骤：** 为每个原子分配唯一的"规范标签"，基于原子性质（原子序数、连接数、电荷等）的拓扑不变量
2. **GENES 步骤：** 从规范标签最小的原子开始，按既定规则遍历图，生成字符串

**但这不等于"解决了所有问题"。** 不同的软件（RDKit、OpenBabel、CDK）使用不同的规范化算法，同一个分子在不同工具中可能产出不同的规范 SMILES。InChI（IUPAC 国际化学标识符）正是为了解决这个跨工具一致性问题而设计的。

### 01.4 不止 SMILES：表示方法的层次

```
1D 表示（标量描述符）:  MW=46.07, LogP=-0.18
    ↑ 信息损失最多，但最简单
2D 表示（拓扑图 + 指纹）:  CCO, 分子图, ECFP4指纹
    ↑ 化学信息学的主战场
3D 表示（构象 + 形状）:  原子坐标 (x,y,z), 静电势网格
    ↑ 信息最丰富，但计算最昂贵
```

本部分聚焦于 2D 表示：从 SMILES 出发，构建分子图，提取指纹和描述符。

## 这些原理会用在哪些判断上

### 01.5 你的 pipeline 中的关键判断点

在实际工作中会反复遇到以下决策点：

| 决策点 | 你需要权衡的 | 错误的后果 |
|--------|-------------|-----------|
| 是否标准化数据？ | 计算成本 vs 数据一致性 | 模型学到标准化 artifact 而非真实化学规律 |
| 选哪种指纹？ | 信息覆盖 vs 可解释性 vs 计算速度 | 错过关键结构-活性关系 |
| 用 Tanimoto 还是 Dice？ | 对分子大小的敏感程度 | 相似性排名失序 |
| fpSize 用 1024 还是 2048？ | 碰撞概率 vs 存储/计算成本 | 对于大分子库，1024 位碰撞率可 > 20% |

### 01.6 为什么要理解原理，而不只是记住操作

**没有人会告诉你"什么是对的"——你需要自己定义。**

没有现成的标准化管线？你需要理解每步操作的化学理由（03 章），才能向合作者说明"这个预处理是合理的"。

没有固定的指纹选择？你需要理解每种指纹捕获的信息类型（04 章），以便根据任务目标（QSAR？相似性搜索？虚拟筛选？）做出有依据的选择。

没有人告诉你怎么定义"两个分子是否相同"？你需要理解标准化和相似性的原理（05 章、07 章），以便建立化合物注册去重的规则。

这就是为什么原理比操作更重要——操作可以复制，判断需要理解。
