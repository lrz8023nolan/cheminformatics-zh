# 07 · 相似性搜索

「两个分子有多像」看似直观，实际是个科学问题——不同的相似性系数会给出完全不同的排序结果。这一章先讨论相似性度量背后的假设，再落到批量相似性搜索与阈值筛选。

## 定义「相像」本身就是科学问题

### 07.1 没有客观的"相似"

> "分子相似性是一个概念，不是一个物理可观测。" —— Willett, 2006

两个分子是否"相似"，取决于你用什么度量、关注什么特征、在什么上下文中。苯和吡啶：从骨架来看（六元芳香环）很相似，从官能团来看（C-H vs N 孤对电子）差异显著。

化学信息学的工作是：**选择一种表征（指纹），选择一个度量（相似性系数），然后接受这个框架下的相似性就是我们的操作定义。**

### 07.2 Tanimoto 系数（Jaccard 指数）

最广泛使用的分子相似性度量，定义如下：

```
T(A, B) = c / (a + b - c)

其中：
a = 分子A指纹中值为1的位数
b = 分子B指纹中值为1的位数
c = A和B共同为1的位数（交集）
```

等价于：共同特征数 / 任一特征数（交集/并集）

**为什么 Tanimoto 是最常用的？**
1. 计算简单：对二元向量只需位运算
2. 对称：T(A,B) = T(B,A)
3. 归一化：始终在 [0, 1] 之间
4. 直观：0 = 无共同特征，1 = 完全相同
5. 行业约定：几乎所有已发表的虚拟筛选基准都使用 Tanimoto

**Tanimoto 的局限性：**
- 对分子大小敏感：一个大分子和一个小分子的 Tanimoto 天然偏低，即使它们共享了大部分结构——因为大分子有更多"额外"的位被置1
- 对指纹密度敏感：MACCS（平均置位密度 ~20-30 bit）和 ECFP4（平均置位密度 ~100-300 bit）计算的 Tanimoto 不可直接比较

### 07.3 Dice 系数与大小敏感性

```
Dice(A, B) = 2c / (a + b)
```

Dice 对分子大小差异**更敏感**。如果分子 A 非常小、分子 B 非常大，即使 A 是 B 的一个完美子结构，Dice 的值也会明显低于 1（因为 B 有很多额外的位）。这使得 Dice 在"寻找精确结构匹配"时更严格，在"寻找子结构关系"时更宽容。

**选择建议：**
- 通用相似性搜索 → Tanimoto（行业标准）
- 子结构/超结构检测 → Tversky（不对称版本，可以调权重）
- 精确去重 → Dice 或 直接比规范 SMILES

### 07.4 Bulk 操作的工程意义

`DataStructs.BulkTanimotoSimilarity(query_fp, library_fps)` 不是简单的 Python 循环。它在 C++ 层面实现了矢量化，对于包含数万分子的库，Bulk 版本比 Python 循环快 10-50 倍。当你的化合物库增长到十万级时，这个差异就是"几秒"和"几分钟"的区别。

### 07.5 相似性阈值的"经验规则"

- **Tanimoto ≥ 0.85（ECFP4）：** 高度相似，通常意味着骨架相同，只有微小修饰
- **0.5 ≤ T < 0.85：** 中等相似，可能共享主要骨架或重要官能团
- **T < 0.5：** 低相似性。但注意：在 ECFP4 下，两个完全不同的分子也可能随机得到 0.1-0.2 的背景相似性（来自偶然的位重叠）

**一个反直觉的事实：** 对于虚拟筛选，Tanimoto = 0.4-0.5 的邻居往往比 0.9+ 的邻居更有价值。过于相似的分子通常是同一系列的类似物（活性已知），而中等相似性的分子可能属于骨架跃迁（活性未知但有新结构类型）。

## RDKit 中的相似性搜索

### 07.6 基础相似性计算

```python
mol1 = Chem.MolFromSmiles("c1ccccc1O")       # 苯酚
mol2 = Chem.MolFromSmiles("c1ccccc1N")       # 苯胺
mol3 = Chem.MolFromSmiles("CCO")             # 乙醇

# 生成 Morgan 指纹
mfpgen = rdFingerprintGenerator.GetMorganGenerator(radius=2, fpSize=2048)
fp1 = mfpgen.GetFingerprint(mol1)
fp2 = mfpgen.GetFingerprint(mol2)
fp3 = mfpgen.GetFingerprint(mol3)

# Tanimoto 相似性（最常用，等于 Jaccard 系数）
sim_12 = DataStructs.TanimotoSimilarity(fp1, fp2)    # 苯酚 vs 苯胺
sim_13 = DataStructs.TanimotoSimilarity(fp1, fp3)    # 苯酚 vs 乙醇
print(f"苯酚-苯胺 相似性: {sim_12:.3f}")    # ~0.3-0.5（共享苯环）
print(f"苯酚-乙醇 相似性: {sim_13:.3f}")    # ~0.05（不相似）

# Dice 相似性（对分子大小差异更敏感）
dice_12 = DataStructs.DiceSimilarity(fp1, fp2)
print(f"Dice: {dice_12:.3f}")

# 其他内置相似性度量
cosine_12 = DataStructs.CosineSimilarity(fp1, fp2)
```

### 07.7 相似性度量的选择

| 度量 | 公式思想 | 适用场景 |
|------|----------|----------|
| Tanimoto | 交集/并集 | 通用，最常用 |
| Dice | 2×交集/(A+B) | 分子大小差异大时更敏感 |
| Cosine | 余弦距离 | 高维空间使用 |
| Tversky | 加权不对称 | 子结构/超结构搜索 |

### 07.8 批量相似性搜索（Bulk Similarity）

在化合物库中查找与查询分子最相似的前 K 个化合物。

```python
# 模拟一个化合物库
library_smiles = [
    "c1ccccc1O", "c1ccccc1N", "c1ccccc1C", "c1ccccc1Cl",
    "c1cccnc1", "c1ccncc1", "CC(=O)O", "CC(=O)OC",
    "CCO", "CCN", "CCC", "O=CO"
]
library_mols = [Chem.MolFromSmiles(s) for s in library_smiles]
mfpgen = rdFingerprintGenerator.GetMorganGenerator(radius=2, fpSize=2048)
library_fps = [mfpgen.GetFingerprint(mol) for mol in library_mols]

# 查询分子
query = Chem.MolFromSmiles("c1ccccc1O")    # 苯酚
query_fp = mfpgen.GetFingerprint(query)

# 批量计算（比循环快得多）
similarities = DataStructs.BulkTanimotoSimilarity(query_fp, library_fps)

# 按相似度排序
results = list(zip(library_smiles, similarities))
results.sort(key=lambda x: x[1], reverse=True)

print("Top 5 最相似分子：")
for smi, sim in results[:5]:
    print(f"  {smi}: {sim:.3f}")
```

### 07.9 相似性阈值筛选

```python
def similarity_filter(query_smiles, library_smiles_list, threshold=0.7):
    """筛选相似度高于阈值的分子"""
    mfpgen = rdFingerprintGenerator.GetMorganGenerator(radius=2, fpSize=2048)
    
    query_mol = Chem.MolFromSmiles(query_smiles)
    if query_mol is None:
        return []
    
    query_fp = mfpgen.GetFingerprint(query_mol)
    
    hits = []
    for smi in library_smiles_list:
        mol = Chem.MolFromSmiles(smi)
        if mol is None:
            continue
        fp = mfpgen.GetFingerprint(mol)
        sim = DataStructs.TanimotoSimilarity(query_fp, fp)
        if sim >= threshold:
            hits.append((smi, sim))
    
    hits.sort(key=lambda x: x[1], reverse=True)
    return hits
```
